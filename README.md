# homepage

박태규 개인 홈페이지 (GitHub Actions + GitHub Pages)

### 🔗 [taegyu-park.github.io/homepage](https://taegyu-park.github.io/homepage/)

- 한국어: https://taegyu-park.github.io/homepage/ko/
- English: https://taegyu-park.github.io/homepage/en/

## 개발

```bash
npm install
npm run dev      # 로컬 개발 서버
npm run build    # dist/ 생성
```

`main`에 push하면 GitHub Actions가 빌드해서 Pages로 배포합니다.
문구는 `src/i18n/`에 한/영으로 모여 있습니다.
